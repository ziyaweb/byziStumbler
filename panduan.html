Panduan Pemakaian

Cara memesan tumbler ByziStumbler, menanyakan stok, dan memahami status order. Semua data tersimpan aman di database kami.

1 Lihat koleksi

  • Scroll ke bagian Collection atau klik slider di beranda.
  • Setiap produk menampilkan harga dan sisa stok secara real-time.
  • Jika bertuliskan Sold Out, produk sedang habis dan tombol order nonaktif.

2 Cara order

  1. Klik tombol Order Now pada produk yang diinginkan.
  2. Isi nama lengkap dan nomor WhatsApp (aktif).
  3. Pilih jumlah (tidak boleh melebihi stok).
  4. Isi catatan jika perlu (misal request khusus).
  5. Klik Kirim Order.
  6. Anda akan mendapat nomor order otomatis, contoh: BZ-20261016-0003.

Setelah order masuk, tim kami akan menghubungi via WhatsApp untuk konfirmasi pembayaran & pengiriman.

3 Tanya stok / custom

  • Buka section Contact di beranda.
  • Isi nama, kontak (WA/email), dan pesan Anda.
  • Kirim — kami akan membalas secepatnya.

4 Status order (untuk admin)

  • pending — order baru, menunggu konfirmasi
  • paid — sudah dibayar
  • shipped — sudah dikirim
  • done — selesai
  • cancelled — dibatalkan

Yang terjadi di balik layar

  • Data produk, order, dan inquiry disimpan di Google Sheets (database gratis).
  • Saat order berhasil, stok otomatis berkurang.
  • Jika stok habis, status produk berubah menjadi soldout.
  • Nomor order & waktu dibuat otomatis (zona waktu Asia/Jakarta).

Butuh bantuan?

Gunakan form Contact di beranda, atau hubungi admin via Instagram / WhatsApp yang tertera di media sosial ByziStumbler.
